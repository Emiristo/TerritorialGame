# PRODUCTION — механика производства

> Статус: утверждённая механика производства.
> Документ является источником требований для реализации и тестирования производства.

## 1. Общая модель

Производственное здание самостоятельно преобразует входные ресурсы в готовый продукт.

Работник производственного здания не выполняет само производство. Его функция — внутренний носильщик между флагом здания и складом здания.

Основная цепочка:

`ресурс → флаг здания → склад здания → производство → продукт → склад здания → флаг здания → логистика`

## 2. Склад производственного здания

Каждое производственное здание имеет **5 складских ячеек**.

- **4 ячейки** предназначены для входных ресурсов производства.
- **1 ячейка всегда зарезервирована под готовую продукцию**.
- Зарезервированная ячейка не может быть занята входным ресурсом.
- Это гарантирует возможность принять готовый продукт после завершения производства.

## 3. Доставка входных ресурсов

Логистика работает для производства по той же механике, что и для строительства.

Цепочка:

`склад → перевозчик → дорога → флаг производственного здания`

Доставленный ресурс **остаётся физически на флаге здания**.

Ресурс на флаге ещё не находится на складе здания и не считается доступным производству до тех пор, пока работник не перенесёт его в складскую ячейку.

## 4. Работник производственного здания

У каждого производственного здания есть свой **специфический рабочий**.

Механически рабочий выполняет функцию носильщика здания и имеет только два типа действий:

### 4.1. Перенос входного ресурса

`флаг здания → склад здания`

Работник забирает поступивший ресурс с флага и помещает его в свободную ячейку входного склада.

### 4.2. Вынос готового продукта

`склад здания → флаг здания`

После производства работник забирает готовый продукт из зарезервированной ячейки и переносит его на флаг здания.

Готовый продукт после появления на флаге передаётся в общую логистику.

## 5. Приоритет действий работника

У работника есть приоритет действий:

**Приоритет №1 — вынести готовую продукцию.**

`склад здания → флаг здания`

**Приоритет №2 — заносить поступившие входные ресурсы.**

`флаг здания → склад здания`

Следовательно, если одновременно:
- на складе есть готовый продукт;
- на флаге находится новый входной ресурс;

работник сначала выносит готовый продукт на флаг.

Во время производства работник продолжает переносить новые поступившие ресурсы с флага на склад здания.

## 6. Запуск производства

Производственное здание автоматически проверяет наличие ресурсов на своём складе.

Когда на складе присутствует полный набор входных ресурсов, необходимый для одной производственной операции, здание запускает производство.

Производство не требует отдельного действия работника.

## 7. Время производства

Продолжительность **одной производственной операции — 15 Simulation Ticks**.

Это единая константа для **всех производственных зданий**.

При этом:

`1 Simulation Tick = 1 игровая секунда`.

Следовательно, одна производственная операция длится **15 игровых секунд**.

## 8. Производство и поступление новых ресурсов одновременно

Во время выполнения производственной операции работник продолжает выполнять свою логистическую функцию.

То есть одновременно возможны процессы:

`производство: ресурсы → продукт`

и

`работник: флаг → склад`

Новые поступившие ресурсы не должны ждать окончания производства, если для них доступны складские ячейки.

## 9. Завершение производства

После окончания 15 тиков производственное здание:

1. завершает текущую производственную операцию;
2. расходует необходимые входные ресурсы;
3. создаёт готовый продукт;
4. помещает готовый продукт в зарезервированную складскую ячейку.

Работник затем должен вынести продукт:

`склад здания → флаг здания`

## 10. Распределение готовой продукции

Когда готовый продукт оказался на флаге производственного здания, общая система логистики определяет его дальнейший маршрут.

Алгоритм:

1. Система проверяет открытые запросы на данный товар.
2. Если существует запрос другого здания — продукт направляется непосредственно этому зданию.
3. Если открытых запросов нет — продукт направляется на ближайший склад.
4. При доставке на склад продукт прибывает на **флаг склада**.
5. Работник склада забирает продукт с флага и помещает его на склад.

Производственный работник не занимается дальнейшей транспортировкой продукции.

## 11. Пример

Для мельницы:

`пшеница → флаг мельницы → работник → склад мельницы`

Когда на складе есть необходимая пшеница:

`склад мельницы → производство 15 тиков → мука → склад мельницы`

Затем работник:

`мука → флаг мельницы`

После появления муки на флаге система проверяет запросы:

- есть запрос на муку → мука отправляется запрашивающему зданию;
- нет запроса → мука отправляется на ближайший склад.

## 12. Принцип разделения ответственности

- **Производственное здание** — преобразует ресурсы в продукт.
- **Работник здания** — переносит ресурсы между флагом и складом здания.
- **Флаг здания** — физическая точка приёма и выдачи груза.
- **Склад здания** — внутренний запас входных ресурсов и готовой продукции.
- **Общая логистика** — транспортирует грузы между зданиями и складами.
