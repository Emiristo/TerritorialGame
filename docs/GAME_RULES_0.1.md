# GAME RULES 0.1

## Назначение документа

Этот документ содержит расширенные правила и проектные решения для развития TerritorialGame. Он используется совместно с `GAME_RULES.md`.

## 1. Рабочие зоны

Каждое здание, имеющее рабочего, определяет свою рабочую зону через универсальный параметр `workZone`.

Поддерживаются два режима:

- `radius` — рабочая зона распространяется от центральной клетки здания по расстоянию Чебышёва;
- `footprint` — рабочая зона совпадает с геометрией здания.

Рабочие зоны могут пересекаться. Пересечение рабочих зон само по себе не создаёт конфликта владения.

Для зданий с внешней добычей используется радиусная рабочая зона. Для зданий, работающих непосредственно на своей территории, используется зона по габаритам здания.

## 2. Рабочие запросы

После завершения строительства активного здания, которому требуется рабочий, для него создаётся запрос на работников.

Запрос содержит владельца, здание, требуемую профессию, необходимое количество работников и список назначенных работников.

Для обычных производственных зданий требуется один работник соответствующей профессии.

Для военных зданий количество требуемых солдат определяется зданием:

| Здание | Требуется солдат |
|---|---:|
| Аванпост | 1 |
| Казармы | 3 |
| Сторожевая башня | 6 |
| Крепость | 9 |

## 3. Работники и профессии

Здание определяет профессию необходимого работника.

Используются профессии:

- лесник;
- лесоруб;
- каменотёс;
- плотник;
- житель;
- фермер;
- мельник;
- пекарь;
- шахтёр;
- сталевар;
- кузнец;
- мастер;
- солдат.

## 4. Инструменты

Профессии, которым требуется инструмент, используют соответствующий инструмент:

| Профессия | Инструмент |
|---|---|
| Лесник | лопата |
| Лесоруб | топор |
| Каменотёс | кирка |
| Плотник | пила |
| Фермер | коса |
| Мельник | мешок |
| Пекарь | скалка |
| Шахтёр | кирка |
| Сталевар | ковш |
| Кузнец | молот |
| Мастер | клещи |

Наличие необходимого инструмента проверяется при создании профессии работника, а не перед каждой рабочей операцией.

## 5. Геометрия зданий

Каждое здание имеет фиксированные размеры `width × height`.

Поворот здания при размещении не используется.

Геометрия здания определяет его занимаемые клетки и, для зданий с `workZone.mode = footprint`, рабочую зону.

## 6. Резервации вокруг зданий

Вокруг каждого здания резервируется одноклеточная зона по расстоянию Чебышёва.

Резервации разных зданий могут пересекаться.

Новое здание нельзя размещать, если хотя бы одна клетка его занимаемой площади попадает в резервацию другого здания.

## 7. Строительство

Строительство выполняется независимо для каждого здания.

Для строительных материалов используются:

- доски — 10 секунд на единицу;
- камень — 15 секунд на единицу.

Материалы обрабатываются последовательно в порядке, определённом строительным рецептом.

Состояния строительства:

```text
PLACED
  ↓
WAITING_FOR_MATERIAL
  ↓
BUILDING
  ↓
проверка
  ├── есть следующий материал → BUILDING
  ├── материала нет → WAITING_FOR_MATERIAL
  └── всё построено → COMPLETED
```

Для состояния строительства не используется агрегированное поле `remainingConstructionTime` или `constructionTime`.

Здание может быть размещено без предварительной проверки наличия всех необходимых ресурсов. Если материала нет, строительство ожидает его доставки.

## 8. Меню строительства

Меню строительства отображается вертикальным списком.

Здания сортируются по общей продолжительности обработки необходимых строительных материалов.

При расчёте используется:

- 1 доска = 10 секунд;
- 1 камень = 15 секунд.

Наличие достаточного количества ресурсов не является предварительным условием отображения здания в меню.

## 9. Размещение зданий

Для размещения необходимо, чтобы весь занимаемый зданием участок:

- находился в пределах карты;
- находился на территории игрока;
- соответствовал требованиям типа местности;
- не был занят другим зданием;
- не попадал в запрещённую резервацию другого здания.

Обычные здания размещаются на равнине. Шахты размещаются на холмах или в горах.

## 10. Штаб и влияние

Штаб имеет размер 3×3 и радиус влияния 10 клеток.

Центр карты находится в районе координат 50×50.

Для обычных зданий базовый радиус влияния составляет 5 клеток.

Штаб также выполняет функцию хранения ресурсов.

## 11. Военные здания

Военные здания изменяют силу влияния территории:

| Здание | Множитель влияния | Солдат | Дополнительный эффект |
|---|---:|---:|---|
| Аванпост | ×0,75 | 1 | — |
| Казармы | ×1,00 | 3 | — |
| Сторожевая башня | ×1,25 | 6 | — |
| Крепость | ×1,50 | 9 | +5% к шансу блока |

Военное здание начинает выполнять свою функцию при наличии требуемого количества солдат.

## 12. Производственные цепочки

Производственные здания используют входные ресурсы и создают выходные ресурсы согласно своим рецептам.

Основные цепочки включают:

- древесина → доски;
- пшеница → мука → хлеб;
- железо + уголь → сталь;
- сталь + уголь → мечи;
- сталь + доски → инструменты;
- золото + уголь → монеты.

Производительность зданий определяется их рецептом и временем одной производственной операции.

## 13. Ферма

Ферма имеет размер 4×4.

Рабочая зона фермы совпадает с её площадью.

Из 16 клеток площади фермы 14 являются пригодными для сельскохозяйственного использования.

Ферма производит пшеницу с базовым циклом 30 секунд на единицу.
