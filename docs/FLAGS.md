# FLAGS — правила флагов

> Статус: утверждённая механика.
>
> Этот документ фиксирует геометрию и правила размещения флагов. Флаг является частью межклеточной структуры карты и не является объектом, расположенным в центре клетки.

## 1. Геометрия флага

Флаг размещается **строго в межклеточном узле** — точке пересечения четырёх соседних клеток World Map.

Для стандартной квадратной сетки допустимы только узлы с целыми координатами:

```text
      cell      cell
         \     /
          \ • /
          /   \
         /     \
      cell      cell
```

Точка `•` является флагом.

Координаты вида:

- `20, 20` — допустимый межклеточный узел;
- `20, 20.5` — недопустимы;
- `20.5, 20.5` — недопустимы.

Флаг не размещается внутри клетки.

## 2. Четыре клетки вокруг флага

Каждый самостоятельный флаг должен находиться между четырьмя существующими клетками:

```text
┌───────┬───────┐
│       │       │
│   A   │   B   │
│       │       │
├───────●───────┤
│       │       │
│   C   │   D   │
│       │       │
└───────┴───────┘
```

Для допустимого узла должны существовать все четыре клетки A, B, C и D.

Флаг не может быть размещён на внешней границе карты, если в результате вокруг него отсутствует одна или более из четырёх клеток.

## 3. Свободные клетки вокруг флага

Самостоятельный флаг разрешается устанавливать только если **все четыре клетки, окружающие узел, свободны от зданий**.

Если хотя бы одна из четырёх клеток входит в `footprint` здания, постановка самостоятельного флага запрещена.

Это правило относится именно к footprint здания, а не только к точке координат флага: флаг физически находится между клетками и поэтому проверяет все четыре прилегающие клетки.

## 4. Территория и влияние

Помимо геометрической проверки, самостоятельный флаг должен:

- находиться на территории владельца;
- находиться в зоне влияния владельца;
- не совпадать с уже существующим флагом.

Все четыре прилегающие клетки должны принадлежать владельцу флага.

## 5. Флаг здания

Каждое здание имеет один собственный логистический флаг.

Флаг здания также является межклеточным узлом и создаётся вместе со зданием в предусмотренной правилами позиции.

Текущая позиция флага здания:

- южная сторона здания;
- `x = origin.x + 1`;
- `y = origin.y + height`.

Флаг здания является частью физической логистики здания и используется как точка передачи грузов.

## 6. Флаг и дороги

Флаг является узлом дорожной сети.

Дорога соединяет два флага и проходит по клеткам World Map.

Дорожное направление использует **8 направлений**, то есть разрешены направления, кратные 45°:

```text
NW   N   NE
 \   |   /
  \  |  /
W ---+--- E
  /  |  \
 /   |   \
SW   S   SE
```

Ограничение поворота дороги — не более 45° между последовательными сегментами.

## 7. Установка флага на существующей дороге

Если межклеточный узел находится на существующей дороге, флаг может быть установлен только при возможности корректно разделить дорогу.

После установки:

```text
Flag A ===== Flag NEW ===== Flag B
          road 1    road 2
```

Исходная дорога превращается в две самостоятельные дороги между новыми парами флагов.

Обе новые дороги должны самостоятельно соответствовать ограничениям дорожной системы, включая минимальную длину.

Если разделение создаёт недопустимый сегмент, установка флага запрещена, а исходная дорога не изменяется.

## 8. Флаг — не склад

Флаг является **точкой передачи груза**, а не полноценным складом.

Груз может физически находиться на флаге в ожидании следующего участника логистической цепочки.

Флаг имеет общую физическую грузовую ёмкость **20 единиц** по всем ресурсам.

Если свободной ёмкости недостаточно для всей передаваемой партии, партия не принимается частично.

## 9. Источник истины

Геометрия флагов должна использовать единую геометрию World Map.

Нельзя создавать отдельную геометрию флагов для логистики, дорог или строительства.

Флаг:

`World Map node → Logistics network node → Road endpoint / transfer point`

## 10. Тестовые обязательства

Тесты должны проверять как минимум:

- флаг в целочисленном межклеточном узле;
- запрет полуцелых координат;
- наличие четырёх прилегающих клеток;
- запрет флага при занятом зданием footprint хотя бы одной прилегающей клетки;
- запрет чужой территории;
- запрет вне зоны влияния;
- запрет уже занятого узла;
- корректное разделение существующей дороги;
- запрет разделения, нарушающего минимальную длину дороги;
- совместимость флага с 8 направлениями дороги;
- сохранение правил грузовой ёмкости флага.
